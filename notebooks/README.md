# Notebooks

One notebook per tutorial module, numbered in session order. Planned modules:

1. `01_tfm_landscape.ipynb` — the tabular foundation model landscape: capabilities, constraints, licenses.
2. `02_first_contact.ipynb` — fitting a TFM directly, and watching it break on real-world data.
3. `03_taming_resources.ipynb` — constraint checks, memory/VRAM estimation, inference-cost management.
4. `04_ensembling_payoff.ipynb` — presets, portfolios, and why the ensemble beats every member.
5. `05_noniid_validation.ipynb` — grouped and temporal validation with `validation_structure`.
6. `06_honest_benchmarking.ipynb` — evaluating on TabArena without fooling yourself.

Keep saved outputs in the committed notebooks so attendees who fall behind can read along.
